# MoodMatch

A social web app that turns mood tracking into an engaging daily game. Users log their mood with an interactive emoji selector, then try to guess their friends' moods. Points are earned for accurate guesses and maintaining streaks.

Key Features:
- Beautiful, animated emoji mood selector
- Daily mood logging with streak tracking
- Social guessing game with points/leaderboard
- Mood patterns and insights dashboard
- Mobile-first responsive design

Tech Stack:
- HTML5/CSS3 with animations
- Vanilla JavaScript for interactivity
- LocalStorage for demo persistence
- CSS Grid/Flexbox for layout
